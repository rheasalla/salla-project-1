# Rhea Salla — Personal Portfolio

A responsive personal portfolio for Project 1, built with HTML and CSS. It introduces Rhea Ann D. Salla, a BSIT student at Kabankalan Catholic College (KCC), and shares her interests in arts and online gaming, her painting hobby, and the honors and artwork awards she described. It also presents suggested creative and learning strengths grounded in her art and BSIT studies.

```text
salla-project-1/
```

## Preview on your computer

Open `index.html` in a web browser. For a local web server, open a terminal in this folder and run:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`. Press `Ctrl+C` in the terminal to stop the server.

## Upload the project to GitHub

1. Sign in to GitHub and create a **new public repository** named `salla-project-1`.
2. Do not initialize the new repository with a README, license, or `.gitignore`, because this project already has its own files and Git history.
3. In a terminal opened in this `salla-project-1` folder, add the remote and push the existing `main` branch. Replace `YOUR-USERNAME` with your GitHub username, or use the exact repository URL shown by GitHub:

```bash
git remote add origin https://github.com/YOUR-USERNAME/salla-project-1.git
git push -u origin main
```

If Git asks you to sign in, complete GitHub's sign-in prompt in your browser. Do not share a password or access token in chat.

## Publish with GitHub Pages

1. Open your repository on GitHub and choose **Settings**.
2. Select **Pages** from the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose branch **main** and folder **/(root)**, then click **Save**.
5. Wait for GitHub to publish the site. Copy the exact GitHub Pages URL displayed in the Pages settings and confirm that it opens publicly.

The usual project-site URL format is `https://YOUR-USERNAME.github.io/salla-project-1/`. Use the exact URL GitHub displays, not a guessed address.

## Make and publish later edits

Edit `index.html` for page content or `styles/style.css` for appearance. After previewing a change, record it in Git and push it to GitHub:

```bash
git add index.html styles/style.css
git commit -m "Describe the change you made"
git push
```

GitHub Pages publishes pushed updates automatically when branch deployment is enabled.
